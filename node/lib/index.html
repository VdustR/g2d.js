@g2d/core

@g2d/core is a Node.js library to transform .gitignore string to .dockerignore string.

Installation​

  • npm
  • Yarn
  • pnpm
  • Bun
npm install @g2d/core detect-newline@4
yarn add @g2d/core detect-newline@4
pnpm add @g2d/core detect-newline@4
bun add @g2d/core detect-newline@4

Usage​

Since detect-newline@4 move to ESM, you can only use g2d/core in ESM:

import g2d from "@g2d/core";

const dockerignore = g2d(gitignore);

Using in Node environment:

./package.json
{
  "type": "module"
}
